# Genre Harness Catalog

Invest in packs in order of rising loop + content surface complexity.

## Tier A — high AI leverage, small loop (build first)

| Pack | Core loop | Content AI owns | Verify |
|---|---|---|---|
| **Arcade score-attack** | Move + shoot/avoid + wave clear | Waves, enemy defs, FX | Frame-step death/score |
| **Match / puzzle grid** | Swap/match → cascade → goals | Levels, obstacles, skins | Solver + sample "fun" set |
| **Top-down dungeon crawl (tiny)** | Explore room → fight → loot → next | Rooms, enemies, items | Path + combat sim |
| **Visual novel / choice story** | Read → choose → branch | Script graph, CGs, UI | Graph reachability |

**Recommended first pack:** Arcade score-attack — tiny loop, clear win metrics, art optional to fun, easy autoplay.

## Tier B — medium (after A is solid)

| Pack | Core loop | Notes |
|---|---|---|
| **Side-view platformer** | Run/jump/attack | Level grammar + softlock detection critical |
| **Turn-based tactics / RPG battles** | Grid move + skill | Balance tables are the product |
| **Idle / incremental** | Click/upgrade/prestige | Economy formula fence first |

## Tier C — hard without a strong human designer

| Pack | Why hard |
|---|---|
| Open-world / large sim | Combinatorial state; AI content fills voids with mush |
| Competitive multiplayer | Netcode + fairness; AI art helps least |
| Narrative open RPG | Quest logic + pacing; needs editor + quest graph harness |

## Product mapping (FutureIndustries)

| Track | Recommended packs |
|---|---|
| Arcade (browser) | Tier A default; Tier B carefully |
| Creator Studio export | Pack choice in interview → zip with harness + playbook |
| Godot download (power user) | Same packs, richer systems; MCP-backed |

Do **not** put Tier C on creators first. 3D / HD-2D visual bar is expensive (Immortal Shores); only after M1–M2 gates are boringly reliable.
